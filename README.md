# HiveMQ Bingo

A bingo card generator for HiveMQ meetings and Slack. Forked from [OxideBingo](https://github.com/johnholloway77/oxideBingo) by John Holloway.

This is not an official HiveMQ product.

## Run it

```bash
npm install
npm run dev
```

## Change the tiles

Edit `public/tiles.json`. Each entry is one phrase. The app picks 24 at random and fills the grid around a free center space.

## Build

```bash
npm run build
```
